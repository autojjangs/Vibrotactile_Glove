# 실험 영상

이 폴더에 다음 네 파일을 원래 이름으로 복사하세요.

- 경로1 내비 영상.mp4
- 경로1 주행 영상.mp4
- 경로2 내비 영상.mp4
- 경로2 주행 영상.mp4

영상은 Git에 포함하지 않습니다. Git clone/pull 뒤 라즈베리파이 프로젝트의 media 폴더로 별도 복사해야 합니다.
원본은 편집·변환하지 않으며 manifest.json에 파일 크기, 해시, 해상도와 길이를 기록합니다.
실행 시 사용한 영상의 실제 해시와 재생 정보는 해당 시행 events.csv에도 저장합니다.

주행 영상: 큰 모니터. 내비 영상: 7인치 LCD (1024×600, 정사각형 영상 비율 유지).
기본 화면 번호는 주행 0, 내비 1이며 config/settings.json의 video.screens에서 바꿀 수 있습니다.
두 영상의 오디오를 모두 사용하고, 라즈베리파이 데스크톱의 기본 오디오 출력으로 재생합니다.
